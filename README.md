# RETRO WORLD by Digital EYE

A free browser arcade: 71 retro, mobile and TV-friendly games, trophies, daily challenges, music, gamepad support, and an EPIC & 3D section (Dust & Iron, Crimson Fang, Popshot: Color Quest and Beat Up Mafia).
Live site: https://retroworld.eu.cc/

## v2 highlights
- New look (`assets/retro-theme.css`)
- Library search, sort, favourites, recently played, Surprise Me, gameplay thumbnails
- 4 new games: Neon Connect, Box Bot, Echo Pad, Merge 2048
- Every game: pause (P), mute (M), CRT effect (C), fullscreen (F), best score, auto-fit to the screen (`games/cartridges/rw-boost.js`)

## v2.9
- NEW EPIC GAME: **Beat Up Mafia**, a top-down open-city crime game (`games/beat-up-mafia/Beat-Up-Mafia.html`, guide at `epic/beat-up-mafia.html`). 7 missions, wanted levels, police helicopter, day/night lighting, radio, boss fight; 11 new trophies and a daily challenge. Contains cartoon violence (13+).

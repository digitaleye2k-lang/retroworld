RETRO WORLD by Digital EYE — Portable Console Edition

PORTABLE / GAMEPAD SUPPORT
- Standard browser Gamepad API support in all 48 games
- Left stick or D-pad = movement
- A / south face button = action, fire or jump
- Start/Menu = start or restart
- B / east face button = close current game
- Live GAMEPAD ON/OFF indicator in the arcade header

Designed for modern handheld gaming PCs and controller-equipped devices,
including Steam Deck-style portable consoles, plus desktop and mobile.

Exact button labels/mapping can vary by device and browser. Touch controls
and keyboard controls remain available as fallbacks.
